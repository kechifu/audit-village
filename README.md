# 稽核新手村

菜鳥稽核員的第一週：繁體中文手機與桌面互動學習網頁。

**[直接試玩](https://kechifu.github.io/audit-village/)**

- 五天十關職場故事、三選一情境題。
- 首答正確得 10 分，最高 100 分；答後顯示回饋、解說與記憶重點。
- 自動保存同一瀏覽器的進度，通關可查看成果及複習錯題。
- 每關提供原文題號與收合的來源節錄。

## 本機開啟

下載或 clone 本專案後，直接以瀏覽器開啟 `index.html`。不用安裝套件；四個執行檔案 `index.html`、`style.css`、`data.js`、`app.js` 請放在同一目錄。

## 維護

原始程式為 TypeScript strict；修改 `src/app.ts` 後執行：

```sh
npm ci
npm run build
```

GitHub Pages 發布 `main` 分支根目錄的靜態檔案。修改程式後請一併提交重新編譯的 `app.js`。

瀏覽器回歸測試需 Playwright 與 Edge，可執行 `npm install --no-save playwright` 後執行 `npm test`。測試包含整輪闖關、計分、接續、來源查看、錯題複習、重玩及手機尺寸排版。

## 內容來源與版本

依使用者提供的《公開發行公司建立內部控制制度處理準則問答集》民國113年10月7日版、十關題庫與故事腳本改編。人物、公司及事件均為虛構。未核對2026年現行法規；實務工作、申報與法遵應查證最新規定及公司制度。遊戲成績不代表專業資格或合規認證。

進度只保存在使用者的瀏覽器，不會上傳個人成績；關閉儲存功能時只能完成本次遊玩。
